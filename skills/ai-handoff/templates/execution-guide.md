# Execution guide

## Target and prerequisites
Provider/surface, actual capabilities/evidence, project root or attachment map, required missing files/decisions, scope and existing stack.
## Prepare context
List exact sources to attach/paste/open; preserve current instruction files. Ask recipient to identify sources actually read and missing ones before consequential work.
## Run prompts in order
Prompt ID/file, prerequisites/dependencies, expected artifacts and checkpoint decisions. Use actual supported host mechanisms; do not invent commands or bypass permissions.
## Verify output
Compare objective/stack/patterns/criteria. Run existing repo checks when available; inspect relevant states/layout if tools permit. Record command/result and provenance; manual/unrun checks explicit.
## Recover
Observed mismatch/evidence → scoped repair prompt → recheck. Preserve correct parts/user edits; request missing diagnostic evidence.
## Deliver/resume
Artifacts/versions, actual checks, unresolved work and next step. Save/read project records through actual tools; export-only does not mark app execution complete.
