# Onboarding

## Problem
Reach first value with minimal setup.

## Use/avoid
Prerequisites/unfamiliar decisions block value; avoid mandatory tours for obvious actions.

## Behavior
Purpose/truthful progress/back/preserved entries; skip optional work only, clarify required prerequisites.

## States
New/in-progress/validation blocked/saving/complete/error; resume if persistence exists.

## Responsive
One readable decision group, continuity across screens.

## Accessibility
Logical headings/labels/focus after steps; accessible errors/progress, avoid forced timed steps.

## Dependencies
Step/form/progress/feedback; type/spacing/action tokens.

## Exceptions
Record optional steps and actual persistence.

## Example
Salon chooses services/hours before bookable slots.
