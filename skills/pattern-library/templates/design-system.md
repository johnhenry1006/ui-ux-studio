# Project design system
## Principles
User task, context, visual direction and project-over-personal overrides.
## Tokens
Authoritative token location and semantic color/type/spacing/radius/elevation/motion rules. Reference values rather than duplicate them.
## Layout and responsive
Hierarchy, containers, content-driven breakpoints and navigation adaptations.
## Components and patterns
IDs, source paths, variants/states, usage boundaries and lock location.
## Accessibility and interaction
Labels, keyboard/focus, errors/announcements, non-color feedback, motion alternatives.
## Exceptions and verification
Decisions, affected screens, actual checks, unresolved drift.
