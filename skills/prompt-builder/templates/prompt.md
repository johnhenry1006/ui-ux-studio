# Task prompt

## Objective
State user outcome and current task result.
## Target artifact type and evidence
Webpage/component/email message/specification/unknown; cite explicit task evidence. When unknown, ask the consequential artifact question before choosing a technology-specific draft. “Email-only” alone does not establish an email-message template.
## Read first
List actual source references, role/revision/status and how recipient receives them. Identify required missing inputs.
## Scope and constraints
Allowed files/screens, excluded changes, stack, project design rules, pinned patterns and local edits to preserve.
## Actions
Concrete steps/dependencies; clarify consequential missing decisions. Use available tools and host permissions only.
## Output contract
Artifacts/paths/screens, structure/fidelity and real vs sample data.
## Acceptance and evidence
Observable criteria with required flags, applicable checks, results and evidence provenance. Unknown/unrun checks remain explicit.
## Completion response
What changed/why; files/patterns; checks actually run and results; failures/unverified items and remaining work. Do not claim the task ran because this prompt was generated.
