# Scoped repair prompt

## Original objective and constraints
Retain agreed user task, stack, project rules, pinned patterns and output contract.
## Observed deviation
Reference actual artifact/diff; expected vs observed; evidence and unknowns.
## Preserve
List correct parts, user edits, data/API contracts and unrelated files.
## Correct
Specify bounded changes that address the observed issue; no automatic rewrite/migration.
## Recheck
Rerun applicable checks, record pass/fail/not_run and evidence provenance. Ask for missing consequential evidence; do not invent the diagnosis.
## Deliver
Changed files/decisions, check results and remaining gaps. Do not mark failed required criteria complete.
