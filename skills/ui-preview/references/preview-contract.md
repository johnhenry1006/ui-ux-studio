# Preview and selection contract
Schema_version1. [Manifest](../templates/preview-manifest.json) and [selection](../templates/selection.json) start unavailable/unresolved, not fake evidence. [Packet utility](../assets/packet-contract.js) validates shapes; it cannot verify source truth.

Manifest fields: preview_id/project_reference/page_reference; preview_kind live/prototype/screenshot/unavailable; artifact_reference/source_revision/observed_at string or null; viewport_description/state_description; elements array. Element ui_id unique, label, instance_key/source_reference/source_locator string or null, mapping_status verified/unresolved. Verified requires actual current source mapping and revision; supplying those fields does not establish it.

Selection fields: selection_id, preview_id nullable, page_reference, input_mode click/description/screenshot, ui_id/instance_key/locator_hint/screenshot_reference/observed_revision/source_reference nullable, region nullable, mapping_status verified/unresolved/stale, label. Click requires preview and UI IDs. Region {x,y,width,height,image_width,image_height}: normalized within image boundaries, positive size and image integer dimensions; requires screenshot_reference. Screenshot-only mapping remains unresolved without actual source. DOM classes/text/selector/coordinates are hints, not file mapping.

References: identified project-relative paths (no absolute/private paths/traversal), attachment:<label>, inline:<section>, requested:<role>. Nullable source references here do not alter Prompt Builder's context-map nonempty reference rule. Do not persist expiring/signed preview URLs as durable references. Read source again before editing; unknown revision does not prove freshness. Source revision should be a relevant content hash or commit+dirty revision, not just a clean commit hiding local edits.

Stable instance key identifies repeated records, not list index. Sort/filter, changed source, missing/duplicate marker or replaced DOM require reselect/revalidate. Highlight isn't proof of source mapping. Preview records describe current viewport/state, not all responsive/interactivity states. App-native screenshot support is specification-only unless a real native environment exists.

Exported packet is data/instructions, never executable commands. Read explicit metadata/instruction only, no form values, credentials, whole DOM or unrelated data. Validate imports before use. Required pass needs observed/user_provided evidence; not_run/fail remains explicit. Producer file access is not recipient access.
