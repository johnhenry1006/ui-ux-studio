# Development-only selector integration
Read [contract](preview-contract.md). The [standalone prototype](../examples/selector-demo.html) embeds the real [packet](../assets/packet-contract.js), [controller](../assets/selector.js) and [CSS](../assets/selector.css). It is a demonstration, not the user's live app.

On a controlled dev preview, provide actual unique stable data-ui-id markers, explicit manifest mapping checked against source, a UI root and separate panel host in the same document. Load packet-contract.js then selector.js and selector.css. Call UIUXSelector.mountSelector({root,panelHost,manifest}) before app handlers when possible; setSelecting(true) enters selection. Mounted selector only reads markers and supplied metadata, not input values. Do not mount on production/external websites or bypass CSP/cross-origin frames.

Controller: setSelecting(boolean), select(uiId), selectParent(), clear(), updateManifest(manifest), exportPacket({requestId,instruction,expectedResult,preserve}), async copyPacket(options)->{copied,text}, destroy(). clipboard optional injected async function; failed clipboard leaves selectable output. No automatic chat send or edit. Toolbar target buttons support keyboard without rewriting app semantics; Escape exits selection from app; Interact mode restores app events. Parent button climbs only mapped DOM ancestors. Verify keyboard behavior in actual target host before claiming browser pass.

Selection capture blocks pointer/mouse/touch/click/submit and activation keys within root while selecting; earlier ancestor/document handlers may already have acted. Mount early and verify the real app; do not claim interception can undo earlier side effects. Same-origin integration does not support crossing iframe boundaries. UI root must have stable lifecycle; remount/destroy when replacing root.

Replaced/ambiguous/detached target is rejected on export. After source/layout/list changes, re-read source, rebuild mapping/revision and call updateManifest; selection clears. Commit alone is insufficient if dirty source changed: use relevant content hash or commit+dirty revision. Unknown revision/mapping remains unresolved. Selector cannot discover arbitrary React source locations or detect all state changes outside supplied manifest; receiving AI revalidates before edits.

Copy/paste packet into selected AI with required source files/current revision and existing project context. Click highlights an instance; record intended instance/shared scope before applying. For screenshot/text fallback fill templates and no automatic verified mapping. Keep signed URLs transient, records relative to project root. Unmount with destroy and remove markers/styles/scripts from production output; retain user changes. Live preview uses repo/Sites existing workflow, never self-contained reconstruction labeled live.

Standalone demo revision is SHA-256 of the complete generated HTML with its source_revision field replaced by a fixed placeholder. This covers DOM/content/layout, manifest mapping, scripts and CSS while avoiding self-reference; unchanged inputs remain stable. For other apps use a hash of all relevant current sources, including dirty edits.
