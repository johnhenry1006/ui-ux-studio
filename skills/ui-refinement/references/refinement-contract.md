# Focused refinement contract
[Change request](../templates/change-request.json) schema_version1: request_id, selection_reference, instruction, expected_result, edit_scope instance/shared, preserve string array, source_revision nullable, affected_consumers/unresolved_items string arrays, acceptance_results. [Selection contract](../../ui-preview/references/preview-contract.md) owns target/preview fields; reuse rather than redefine.

Default instance, one target and requested properties only. Stable keyed content changes belong to correct data/prop/record, not a whole template. Shared component/CSS/token work searches actual imports/usages plus inventory, including omitted consumers. Use compatible local variant/prop/scoped style for local request. If it cannot preserve other consumers safely, clarify local/shared impact before edit; explicit authorized shared scope needs no repeated approval. No automatic stack/pattern migration, cloned component for a text edit, global overrides or whole-page rewrite.

Read current source/Git changes and pin revisions immediately before editing. Stale positional index, unknown revision or conflicting mapping requires focused resolution. Export packet creation doesn't execute. Direct edits need actual tooling and task authorization. Existing workflow evidence governs complete/blocked; no new state engine.

Acceptance row criterion_id unique, required boolean, status pass/fail/not_run, evidence_reference string/null, evidence_provenance observed/user_provided/none, note string. Pass requires evidence and non-none provenance; shape validation doesn't prove acceptance. Required failed/unrun/missing evidence blocks completion; source-only optional browser not_run disclosed without changing required flags.

Store original task-owned patch and relevant before/after revisions in project record when needed for reversal. Inverse patch only if current corresponding hunks still match attributable after-state; overlapping user edits or missing patch evidence require resolution before reversal. Never reset whole repository or overwrite user edits. Preview instrumentation is development-only and removed from production artifact. Record actual source/preview revisions and refresh gaps; old visual checks don't validate changed source.
